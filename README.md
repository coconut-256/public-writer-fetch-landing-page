# 公众号文章批量下载md浏览器插件

先看效果

![image-20260514161319001](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260514161319001.png)



先问大家一个问题。

你的微信收藏夹里，有多少篇公众号文章，是收藏完之后再也没打开过的？

我自己刚翻了一下，光是这个月，就攒了快 50 篇。

打开率，0。

每次刷到好文章，第一反应都是"先收藏，回头细看"。然后从来没有"回头"过。

这病我得了好几年。估计你也一样。

所以今晚我搞了个东西。

把一个公众号几百篇历史文章——对，所有的——5 分钟全扒下来，再花 5 分钟丢进 AI 知识库。

从此想找哪句话、想问哪个观点，直接 @ 它。

爽爆了。

正经讲一下。

收藏夹的问题不是"我没看"，是**信息散、找不到、用不上**。

你以为你拥有那篇文章，其实你只是给腾讯服务器加了一行收藏记录。

下次想用的时候，关键词记不清、标题想不起来，全等于零。

但丢进 AI 知识库以后，整个事情就换了一个游戏。

你不用再"找"，你只需要"问"。

AI 会从几百篇里，把相关段落给你拽出来，再帮你串成一个回答。

这才叫真正的拥有。

今天用的东西就两样:

1. 一个浏览器插件(批量扒文章)
2. 腾讯 ima(装文章 + 问问题)

全程不用写一行代码,也不用部署任何东西。

下面手把手。

**第 0 步:你得有一个自己的公众号。**

没有的话现在去注册一个,3 分钟搞定。

电脑端:https://mp.weixin.qq.com/cgi-bin/loginpage

手机端搜 "公众号助手" app。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260509235042731.png)

为啥要这步?因为这个插件是挂在公众号后台用的——它本质上是"借"了公众号后台搜索其他号的能力,把文章列表抓下来。

没有自己的号,就没有入场券。

**第 1 步**:解压 zip 到任意目录。

**第 2 步**:浏览器打开 `chrome://extensions/`。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260509235411034.png)

**第 3 步**:右上角打开"开发者模式"。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260509235958010.png)

**第 4 步**:点"加载已解压的扩展程序"→ 选解压出来的那个目录。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260510000223570.png)

**第 5 步**:登录公众号后台首页,右上角就会冒出一个绿色的"查看竞品公众号"按钮。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260509234900938.png)

**第 6 步**:点开,搜你想扒的公众号,一键导出 md。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260510000331331.png)

整个过程,不夸张,真的就 1 分钟。

我第一次用的时候有点懵——这玩意儿合法吗?

后来想了想,搜出来的都是已经公开发布的文章,本质上和你手动一篇篇打开复制是一回事,只是替你省了时间。

合规边界,自己把握。

**二. 把文章丢进 ima 知识库**

ima 是腾讯自己的 AI 知识库产品,免费、好用、对中文友好。

下载链接(用我的专属链接进,能免排队解锁 copilot 功能):

https://ima.qq.com/copilot-apply-unlock?id=V_5sR6LUxrmsC0Af8KXIyg

手机用户专属——20G 知识库空间限时领:

https://ima.qq.com/mp-user-space-share?channel=10000105

装好以后,新建一个知识库。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260510122321656.png)

然后是关键的一步:把刚才扒下来的 md 文件全丢进去。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260510122412911.png)

ima 支持两种方式上传:网页链接 / 本地 md 文件夹。

两种我都试过——

**少量内容**(十几篇):直接复制公众号文章网址,丢链接就行。一次能丢 10 个。

**大量内容**(几百篇):把刚扒下来的 md 文件夹整个拖进去。

如果嫌一篇篇丢麻烦,ima 自己出了一个 skill,让小龙虾帮你自动上传——你说一句"把 D 盘那个文件夹里的所有 md 全传到我刚建的知识库",它就开始干活。

![](https://cdn.jsdelivr.net/gh/coconut-256/img-bed/images/image-20260510122616430.png)

这个 skill 我装上以后真的爱不释手。

我以前自己写过一个上传脚本,每次都得改路径、改 token,麻烦得要死。

现在一句话,比写代码丝滑十倍。

**三. 知识库到底怎么用**

文件传完,左下角会有个"训练中"的小圈圈在转。

转完就可以问了。

我拿可可耐特自己的号当测试。把过去几百篇全部丢进去,然后开始拷打——

"我之前写过一篇关于多 Agent 协同的文章,提到三省六部制的,那篇大概的核心观点是什么?"

它咔咔几秒,把那篇文章的核心论点 + 相关段落原文,全引出来给我。

"我之前对'AI 替代软件'这件事的判断,和最近的判断有什么不一样?"

它给我做了一个时间线对比。哪一篇几月几号写的、当时什么观点、后来又怎么演化的,列得清清楚楚。

我看到那一刻是真震惊的。

这不是简单的"搜索"。

它做的事情,是把我过去散落在不同文章里的思考,**重新组织成一个可以对话的"我"**。

我的过去,第一次变成了一个可以问的对象。

**四. 这玩意儿对普通人意味着什么**

跨个界类比一下。

博尔赫斯写过一篇短篇叫《巴别图书馆》。

他说宇宙是一座图书馆,里头藏着所有可能的书——所有真理、所有谎言、所有还没发生的事。

但住在里头的人,毕生都在游荡寻找。

绝大多数人,到死都没找到自己想要的那一本。

你的收藏夹,就是一座微缩版的巴别图书馆。

里面什么都有——你某天看到的金句、某个深夜被打动的段落、某个大牛的实战思路——但你找不到。

而 AI 知识库做的事情,是给这座图书馆装了一个馆长。

你说一句话,它就把你想找的那一页翻出来。

我们这代人最大的资源不是钱。

而注意力最大的浪费,不是刷短视频。
